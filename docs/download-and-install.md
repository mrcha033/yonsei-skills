# 터미널 없이 Yonsei Skills 설치하기

코드나 명령어를 몰라도 됩니다. 사용하는 앱에 맞는 파일 하나만 받으세요.

## 운영체제별 지원

| 기능 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 셔틀 조회·예약·취소 | 공식 브라우저 | 공식 브라우저 | 공식 브라우저 |
| 공간 검색·신청 | 공식 브라우저 | 공식 브라우저 | 공식 브라우저 |
| 무료 증명서 PDF | 로컬 PDF 프린터 | 로컬 PDF 프린터·CUPS 인쇄 | 로컬 PDF 프린터·CUPS 인쇄 |
| 증명서 실물 인쇄 | 공식 ReportX | 저장한 PDF를 CUPS로 인쇄 | 저장한 PDF를 CUPS로 인쇄 |

브라우저 작업은 앱이 연세 전용 Chrome·Edge·Chromium 창을 한 번
엽니다. 공식 로그인 화면에서 학생이 직접 로그인하면 그 전용
프로필을 계속 재사용하므로 매번 로그인할 필요가 없습니다. 현재
브라우저 연결을 지원하는 앱에서는 이미 열린 공식 탭도 이어 쓸 수
있습니다. 비밀번호나 쿠키를 도구에 넘기거나 별도 명령어를 실행할
필요가 없습니다.

포털·Underwood·LearnUs·전자출결·셔틀·증명서는 학교 SSO를 이어
사용합니다. 공간대관은 별도 로그인 화면을 쓰므로 같은 관리
브라우저에서 최초 한 번 추가 인증할 수 있습니다. 두 경우 모두
비밀번호는 공식 화면에만 입력합니다.

Windows·macOS·Linux의 무료 출력 PDF는 학교의 인증된
**인터넷즉시발급 → 프린터 출력** 응답을 로컬에서 렌더링한 결과입니다.
별도 유료 상품인 전자서명 전자증명서가 필요하면 운영체제와 관계없이
공식 **전자증명서발급** 메뉴를 사용하세요.

세 운영체제용 플러그인에는 재배포 허가를 받은 `연세제목.TTF`와
`연세본문.TTF`가 포함되어 있어 따로 설치할 필요가 없습니다. 두 글꼴
파일을 모두 검증하고 실제 증명서 서식이 참조한 글꼴만 PDF에 넣습니다.
파일 해시가 맞지 않거나 다른 글꼴이 섞이면 대체하지 않고 발급 전에
중단합니다.

## Codex 데스크톱 앱

1. [Codex용 ZIP 받기](https://github.com/mrcha033/yonsei-skills/releases/latest/download/yonsei-codex-ui-pack.zip)를 누릅니다.
2. 다운로드한 ZIP을 더블클릭해 압축을 풉니다.
3. Codex 데스크톱 앱에서 압축을 푼 `yonsei-skills` 폴더를 엽니다.
4. 앱을 한 번 다시 시작하고 **Plugins**를 엽니다.
5. **Yonsei Skills - 학생생활**에서 먼저 **오늘의 연세·포털 연결**의
   `+`를 누릅니다. 이 항목이 8개 학교생활 기능의 공통 로그인과 빠른
   명령을 제공합니다.
6. 필요한 전문 도구(수강계획, 졸업, 셔틀, 공간, 증명서 등)도 `+`를
   눌러 추가합니다.
7. 새 작업을 열고 “내 졸업요건 계산해 줘”처럼 평소 말하듯 요청합니다.

플러그인이 안 보이면 다른 폴더가 아니라 `.agents` 폴더가 들어 있는
`yonsei-skills` 폴더 자체를 열었는지 확인하세요.

## Claude 웹·데스크톱

1. [Claude용 ZIP 받기](https://github.com/mrcha033/yonsei-skills/releases/latest/download/yonsei-student-life.zip)를 누릅니다.
2. Claude에서 **Customize → Skills → + → Create skill → Upload a skill**로 이동합니다.
3. ZIP을 풀지 말고 그대로 업로드합니다.
4. **연세 학생생활 도우미**를 켜고 새 대화를 시작합니다.

`.skill` 파일을 받는 화면이라면
[yonsei-student-life.skill](https://github.com/mrcha033/yonsei-skills/releases/latest/download/yonsei-student-life.skill)을
대신 선택해도 됩니다.

Claude 웹에서는 공지, 시간표, 마일리지, 졸업계획과 자료 정리는 사용할
수 있습니다. 사용자의 학교 브라우저를 직접 눌러야 하는 셔틀 예약, 공간
신청, 증명서 발급은 초안과 최종 확인 내용까지 준비하고 실제 클릭은
브라우저 제어가 있는 데스크톱 환경에서 진행해야 합니다.

## 설치 후 첫 질문

- “연세 포털에 한 번 로그인하고 오늘 할 일을 정리해 줘.”
- “이번 주에 놓치면 안 되는 연세대 공지를 찾아 줘.”
- “내 성적표와 2024학번 전공요건을 비교해 줘.”
- “내 마일리지 이력과 현재 정원을 고려해서 마일리지를 나눠 줘.”
- “지금 열려 있는 학사신청과 장학금 마감을 정리해 줘.”
- “생활관 외박 신청을 이번 주 금요일로 준비해 줘.”
- “교환학생 준비에서 다음 서류와 마감을 알려 줘.”
- “교직이수에서 남은 교육·실습 요건을 계산해 줘.”
- “교육실습 확인서를 PDF로 발급해 줘.”
- “내일 오전 9시쯤 신촌에서 국제캠퍼스로 가는 셔틀을 찾아 줘.”
- “이번 주 LearnUs 과제와 마감일을 정리해 줘.”

이 요청들은 공통 관리 브라우저와 각 전문 플러그인을 함께 사용합니다:
오늘의 연세, 학사신청·장학, 수강 마일리지, 졸업·교직, 셔틀,
공간·생활관, 증명서, LearnUs·출결. 학생은 기능 이름이나 명령어를
외울 필요가 없습니다.

## 사용할 때 보이는 흐름

1. 학생이 평소 말로 요청합니다.
2. 에이전트는 날짜·시간·인원처럼 정말 부족한 내용만 질문합니다.
3. 예약이나 신청이면 후보와 최종 내용을 한 번 보여 줍니다.
4. 학생이 확인하면 한 번만 실행하고 예약번호·신청 상태·PDF 경로처럼
   가장 중요한 결과 하나를 먼저 알려 줍니다.

학교 화면이 바뀌거나 세션이 만료돼도 기술 오류나 화면 선택자를 그대로
보여 주지 않습니다. 다시 로그인, 최신 후보 재조회, 공식 내역 확인처럼
학생이 바로 할 수 있는 다음 행동을 안내합니다.

비밀번호, OTP, 세션 쿠키는 채팅에 입력하지 마세요. 학교 로그인이
필요하면 도구가 공식 로그인 화면을 열어 둡니다. 그 화면에서 한 번
로그인하면 같은 관리 브라우저 프로필을 포털·LearnUs·출결·셔틀·도서관
작업에 이어 사용합니다. 공간처럼 별도 로그인을 쓰는 서비스는 최초 한
번 추가 인증하며, 학교 세션이 만료되면 그때만 다시 로그인합니다.
