# 연세 포털 학생 편의기능 조사

확인일: 2026-07-30

공식 포털 화면, 포털의 공개 링크 지도, 현재 링크 조회 응답, 각
학생 서비스의 공개 첫 화면을 읽기 전용으로 확인했다. 로그인, 신청,
예약, 취소, 결제, 메시지 전송은 수행하지 않았다.

## 포털 구조

- 공식 포털: `https://portal.yonsei.ac.kr/ui/index.html`
- 공개 링크 지도:
  `https://portal.yonsei.ac.kr/ui/thirdparty/portal/lib/js/linkAddress.js`
- 현재 링크 조회 응답에는 공통·신촌·미래를 합쳐 59개 항목이 있다.
- 포털의 `href="#"`는 실제 서비스 주소가 아니다. 화면에서 서비스
  이름을 누를 때 현재 링크 정보로 목적지를 정한다.
- 로그인 전 화면에서도 학사, IT, 행정, 캠퍼스별 서비스 분류는 보이지만,
  개인 성적·학적·예약·대출 상태는 각 서비스 로그인 뒤에만 확인할 수 있다.

## 가장 먼저 해결할 로그인 경험

학생이 서비스마다 비밀번호를 다시 입력하거나 터미널에서 로그인하게
해서는 재방문이 생기기 어렵다. 기본 흐름은 다음과 같다.

1. 학생의 지속형 Chrome 프로필에서 공식 포털을 연다.
2. 이미 로그인되어 있으면 묻지 않고 바로 요청한 서비스로 이동한다.
3. 로그인이 필요할 때만 공식 화면을 그대로 열어 두고 학생이 한 번
   완료한다.
4. 같은 브라우저 프로필로 학사·LearnUs·출결·셔틀·공간·도서관 등을
   계속 연다.
5. 개별 서비스가 별도 기관 로그인을 요구하면 그 화면만 한 번 더
   연결한다.
6. 세션이 만료되면 마지막 읽기 단계부터 재개한다. 결과가 불확실한
   예약·신청·발급·결제는 자동 반복하지 않는다.

도구는 비밀번호, OTP, 쿠키, 브라우저 저장소를 읽거나 복사하지 않는다.
연세의 여러 서비스가 서로 다른 도메인과 애플리케이션 세션을 사용하므로
“한 쿠키로 영구 로그인”을 약속할 수는 없다. 학생이 보는 로그인 횟수를
최소화하고, 기존 공식 브라우저 세션을 잃지 않는 것이 현실적인 목표다.

## 이번 릴리스에 반영한 기능

| 기능 | 학생 요청 예시 | 재방문성 |
| --- | --- | --- |
| 한 번 로그인 | “연세 포털 로그인하고 계속 이어서 써 줘” | 모든 인증형 기능의 기반 |
| 자연어 바로가기 | “도서관 스터디룸 예약 화면 열어 줘” | 주 1회 이상 |
| 오늘의 연세 | “오늘 수업, 마감, 출결, 예약 정리해 줘” | 매일 |

`오늘의 연세`는 접근 가능한 공식 화면에서 다음 항목만 읽는다.

- 오늘 수업과 다음 캠퍼스 이동
- LearnUs의 오늘 또는 7일 안 마감
- 결석·지각·확인할 출결
- 활성 셔틀·공간·도서관 예약
- 7일 안에 반납할 도서
- 구체적인 신청·납부·행사 마감이 있는 공식 공지

## 다음 구현 우선순위

### 1. 도서관 생활 도우미

신촌 도서관은 좌석·실 현황 및 예약, 자료 대출·연장·예약·반납,
캠퍼스간 대출, 대출 현황, 예약 현황을 제공한다. 시험기간에는 매일,
평소에도 주 단위 재방문 가능성이 높다.

다음 기능:

- 반납 7일 전·3일 전 알림
- 연장 가능한 책만 모아서 확인 후 연장
- 현재 좌석과 그룹스터디룸 후보 비교
- 선택한 좌석·방을 확인받아 한 번만 예약

공식 출발점: `https://library.yonsei.ac.kr/`

### 2. 학사 일정·신청 도우미

학사정보시스템과 학교 학사지원 메뉴에는 수강, 성적, 전공, 휴·복학,
등록금, 장학금, 증명서와 각종 신청서가 흩어져 있다. 매일 쓰지는 않아도
기한을 놓쳤을 때 손실이 커 학기 초·말 재방문 가치가 높다.

다음 기능:

- 개인 상황에 맞는 학사 마감 달력
- 휴학·복학·전공신청·졸업신청 준비물 점검
- 공식 신청 화면 바로가기와 제출 전 검토
- 등록금 고지·납부확인·반환 시점 안내

공식 출발점:

- `https://www.yonsei.ac.kr/sc/199/subview.do`
- `https://www.yonsei.ac.kr/sc/296/subview.do`
- `https://www.yonsei.ac.kr/sc/393/subview.do`

### 3. 장학금·등록금 매칭

기존 공지 검색에 학적, 학년, 전공, 소득구간, 복학 예정 여부를 사용자가
선택해서 넣으면 지원 가능한 장학금과 신청 경로를 좁힐 수 있다.

다음 기능:

- 지원 가능성이 있는 공고만 추리기
- 중복수혜·휴학·복학 조건 경고
- 신청 마감과 등록금 고지 반영 여부 확인

### 4. 커리어 주간 플래너

커리어연세는 채용정보뿐 아니라 진로역량, AI 진로추천, 졸업선배 멘토링,
커리어 포트폴리오, 상담·VR 모의면접을 제공한다. 미래캠퍼스
경력개발포털은 프로그램 신청, 멘토링, 활동기록부, 세미나실 예약을
제공한다.

다음 기능:

- 전공·희망직무 기반 프로그램과 채용 공고 주간 추천
- 상담·멘토링 가능한 시간 비교
- 교내 활동을 커리어 포트폴리오 항목으로 정리

공식 출발점:

- `https://career.yonsei.ac.kr/`
- `https://myjob.yonsei.ac.kr/`

### 5. 비교과·상담 통합

미래캠퍼스 With YONSEI에는 AI 전공·교과 추천, 비교과 프로그램,
자기개발 마일리지, 진로·학업·심리·생활관 상담, 각종 진단이 한곳에 있다.
신촌 상담센터는 상담 신청, 신청 내역, 자가진단을 제공한다.

다음 기능:

- 신청 중인 프로그램과 마감 통합
- 적합한 상담 종류 안내와 예약 화면 연결

공식 출발점:

- `https://with.yonsei.ac.kr/`
- `https://counsel.yonsei.ac.kr/ysclinic/index.do`

### 6. 생활관·건강·학생증

미래생활관은 입·퇴사 공지, 고장·수리 접수, 생활 안내를 제공한다.
학생건강공제회는 진료비 공제 대상, 서류, 접수기한을 안내한다.
학생증 발급은 로그인 뒤 진행한다. 모두 필요할 때의 가치는 높지만,
일상 재방문은 앞선 기능보다 낮다.

다음 기능:

- 생활관 신청·등록·결핵검사 마감 확인
- 고장·수리 접수 초안과 처리상태 확인
- 진료비 공제 가능성·구비서류·접수기한 계산
- 신입생 학생증 발급·재발급 체크리스트

공식 출발점:

- `https://wjdorm.yonsei.ac.kr/wjdorm/index.do`
- `https://yis.yonsei.ac.kr/healthma/intro/center.do`
- `https://ysid.yonsei.ac.kr/ysidmaster/front/main.do`

## 보류할 기능

- 웹메일 전체 자동화: 메일 제공자와 권한 범위를 먼저 확인해야 한다.
- 출석 체크 대행: 위치·비콘·수업 참여를 대신 증명하면 안 된다.
- 수강신청 최종 제출: 경쟁·대기열·사용자 선택의 영향이 커 현재는 계획과
  마일리지 전략까지만 제공한다.
- 유료 증명서 결제: 무료 프린트 호환 흐름과 분리하고 별도 확인이 필요하다.
- ERP 로그인: 현재 관측된 레거시 리다이렉트에 HTTP 구간이 있어 학생용
  라이브 인증 경로로 사용하지 않는다.
