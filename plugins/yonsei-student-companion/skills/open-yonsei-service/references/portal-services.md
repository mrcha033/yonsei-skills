## Routing notes

- `학사`, `등록금`, `장학`, `휴학`, `복학`, `전공`, `성적`, `졸업`:
  start with 학사정보시스템.
- `책`, `대출`, `연장`, `좌석`, `스터디룸`: start with the campus library.
- `취업`, `멘토링`, `상담`, `포트폴리오`, `채용`: use 커리어연세 or
  미래 경력개발포털.
- `심리상담`, `상담 예약`, `자가진단`: use the campus counseling center.
- `비교과`, `자기개발 마일리지`, `AI 전공 추천`: Mirae students use
  With YONSEI.
- `기숙사`, `입사`, `퇴사`, `고장 수리`: the portal currently exposes
  미래생활관 directly; verify the current Sinchon/International dormitory
  source separately rather than misrouting it.
