session. Read the smallest relevant view.

## Optional campus sources

- Mirae: 통학버스, 미래생활관 notices and repair status, With YONSEI
  program applications, W-캘린더, chapel notices.
- Sinchon/International: 커리어연세 appointments and programs, counseling
  booking, library seats and group-study rooms.

Do not infer a task from a generic promotional notice. Include it only when it
has a date, a student-relevant action, and an official source.
