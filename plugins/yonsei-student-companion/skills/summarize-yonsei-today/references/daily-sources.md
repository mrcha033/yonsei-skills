## Separate specialist requests

Shuttle/space/library reservations, notices, tuition, dorm, and exchange are
not currently collected by the preferred `today` command. When the student
asks for one of them, invoke its specialist workflow separately and label that
result separately instead of claiming it was part of the daily aggregate.

Do not infer a task from a generic promotional notice. Include it only when it
has a date, a student-relevant action, and an official source.
