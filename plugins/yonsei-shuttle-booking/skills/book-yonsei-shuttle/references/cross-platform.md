# Cross-platform browser path

Use the same official shuttle page on Windows, macOS, and Linux. Prefer the
student's already open Chrome or Codex desktop browser profile so a successful
Yonsei login survives navigation. Do not open a temporary profile.

Run `scripts/platform_support.py` internally when the host is unclear. A
supported desktop path must report `persistent-desktop-browser`; students do
not need to run this script themselves.

If the current product cannot control a desktop browser, prepare the shortlist
and exact confirmation summary, keep the official page open when possible, and
stop before reservation, waitlist, or cancellation.
