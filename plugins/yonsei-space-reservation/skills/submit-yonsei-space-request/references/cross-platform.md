# Cross-platform browser path

Use the same official space-reservation page on Windows, macOS, and Linux.
Prefer the student's already open Chrome or Codex desktop browser profile so
the Yonsei login remains available. Do not open a temporary profile.

Run `scripts/platform_support.py` internally when the host is unclear. A
supported desktop path must report `persistent-desktop-browser`; students do
not need to run this script themselves.

If the current product cannot control a desktop browser, prepare the room
shortlist, application fields, and exact confirmation summary, then stop before
submission. A submitted request is not an approval.
