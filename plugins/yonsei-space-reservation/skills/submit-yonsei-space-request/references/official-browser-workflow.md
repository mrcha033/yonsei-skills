# Official space submission workflow

Official service: `https://space.yonsei.ac.kr/`

The affiliated-user guide checked on 2026-07-30 describes these separate
stages:

1. sign in;
2. choose date, headcount, room, and time;
3. submit an application;
4. wait for staff approval;
5. pay when the approved space is paid;
6. receive the approval notice;
7. print and present the permit.

A successful application is therefore not an approval or a reservation permit.
The browser workflow must read back the official application history after
submission and preserve the displayed request number and status.
